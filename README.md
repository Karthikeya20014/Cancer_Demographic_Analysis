# Cancer_Demographic_Analysis
Analyzed cancer cases and deaths across demographic, temporal, and geographic dimensions (2022–2026) to identify key patterns and healthcare insights.

## Cancer Demographic Analysis Project

### Overview
This project analyses cancer cases and deaths across gender, age groups, cancer types, stages, and states over the period 2022–2026. The objective is to identify demographic, temporal, and geographic patterns in cancer incidence, mortality, and survival, providing meaningful insights into the populations and regions most affected and supporting data-driven healthcare planning and intervention.

## 📊 Objectives
- Identify root causes for Deaths due to Cancer.
- Analyze Cancer Deaths by Gender, AgeGroup, CancerType, StateWise and more features
- Build KPI dashboard

- ## 📁 Project Structure
- dashboards/ → Excel dashboard and Data Cleaning
- sql/ → SQL queries and Exploratory Data Analysis(EDA).
